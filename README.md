# 📚 BOOKStore

BOOKStore is a RESTful backend API for a bookstore application built with **Node.js, Express.js, and MongoDB**.

This project was developed as a learning project to practice backend development, REST API design, MongoDB database management, Mongoose, CRUD operations, and a structured backend architecture.

---

## 🚀 Features

- 📚 Book management
- ➕ Create books
- 📖 Retrieve books
- 🔍 Retrieve a single book by ID
- ✏️ Update books
- 🗑️ Delete books
- 🌱 Database seeding
- 🗄️ MongoDB database integration
- 🔗 Mongoose ODM
- 🌐 RESTful API
- 🧩 Controller, Model, and Route separation
- ⚙️ Environment variable configuration
- 🔄 Development support with Nodemon
